# OXR_Switcher (x32/x64)

**English**

OpenXR Runtime Switcher - GUI util for switch active OpenXR Runtime (x32/x64). Displayed in a list everything that is installed on the system runtimes. Supported icons: `Oculus`, `Meta`, `SteamVR`, `VirtualDesktop`, `WMR`, `Vive`, `Varjo`, `Pimax`, `Monado`. 

To quickly change the active OpenXR Runtime: create a shortcut and add the parameter - the OpenXR Runtime number from the list. The `demo` parameter is for demonstration mode.

**Русский**

OpenXR Runtime Switcher - Утилита для переключения активной среды OpenXR (x32/x64). Отображает в списке все установленные в системе среды. Поддерживаются иконки: `Oculus`, `Meta`, `SteamVR`, `VirtualDesktop`, `WMR`, `Vive`, `Varjo`, `Pimax`, `Monado`. 

Для быстрой смены активного OpenXR Runtime: создайте ярлык и добавьте парамер - номер OnenXR Runtime из списка. Парамерт `demo` - для режима  демонстрации.
